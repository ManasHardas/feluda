# jtbd: Neighborhood Watchdog's to-do list

- `todo.md`: the live list, in priority order. Each item has a **Done when**.
- `done.md`: finished items, with date and commit.
- `items/NNN-slug.md`: background for an item, linked from `todo.md` (create when needed).

Rules:
- Add every new task, idea or open question the moment it appears, with a Done when.
- The moment something is finished, move it to `done.md` with the date and the PR or commit.
- Decisions live in `ai/docs/decisions/`, not here.
- At the start of every session read `todo.md` and be ready to say what is open.
