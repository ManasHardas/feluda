# Changelog

Each released version has a section here. The "Release" workflow refuses to release a version
without one, and shows its text to testers in TestFlight and Firebase App Distribution, so write it
for residents: what changes for them, in plain words.

## 1.0.0

First release for residents.

- Join with the invitation link for your home. Only your street is asked; the house number is optional.
- Your phone reports when Wi-Fi, internet or mobile service drops and comes back. When several homes
  lose connectivity at the same time, everyone taking part gets a notification.
- If this version ever becomes too old to work with the server, the app says so and shows where to
  get the update.
